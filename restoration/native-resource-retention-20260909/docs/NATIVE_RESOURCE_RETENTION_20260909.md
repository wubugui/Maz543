## 完整资源统计

`resource-census=1` 仅在开发模式输出一次原生资源统计。统计 geometry 的 index、普通/交错属性及所有 morph target，按底层 ArrayBuffer/SharedArrayBuffer 去重；共享 backing 只计一次。沿完整根节点遍历，包含不可见总成，不用当前视锥或可见性当作删除依据。该数值只代表所跟踪几何的 CPU 缓冲引用，不能替代 JS 可达堆、贴图、驱动或 GPU 内存。

30 份不再被装配根引用的旧几何仅独占 1,422,144 bytes，主要包含已复制为运行时扭转几何的原扭杆等替换源。这个量远小于此前数 GB 进程占用，不能把它认作主要根因。几何数量是共享去重口径，与 UI 的 8868 登记实例口径不同。

## 按引用清理

`RenderResources.releaseReplacedGeometry` 只在七个原生资产装配完成、运行时几何克隆已登记后调用。保留装配根所有 Mesh/Line/Points 的几何，包括隐藏内构及备用总成；仅对不再引用的几何调用 dispose 并删除资源集合/诊断标签引用。材质和贴图仍持有，因为导出或外观映射也可能直接引用它们。

不改变剩余 BufferAttribute、morph、索引、矩阵、材质或拓扑；不压缩、不量化，不根据屏幕可见性释放部件。清理释放的是本资源登记器的持有关系，没有强制 GC，也不宣称操作系统立即返还 1.42 MB。部分旧资源此前已有 GPU dispose，本次同时去掉残留 CPU 引用。
