# 原顺序深度前序遮挡复用实验

完整 goal ACTIVE，整车 16 项验收仍 OPEN。本阶段为开发实验，普通预览不启用；动态性能问题没有解决。

## 方法与边界

`lib/occlusionPrefixReuse.ts` 在原始绘制上附加异步 `ANY_SAMPLES_PASSED_CONSERVATIVE` 查询。仅当前目标自身深度输入和之前全部深度写入的有序序列逐项相同时，复用零样本结果。序列采用无碰撞 token 树，输入使用 Object.is，不使用近似矩阵、包围盒或哈希判定。保留原始三角形、材质、机械更新与各通道实际采样数；不复用阴影查询，不跨 4/2/0 MSAA 目标挪用结果。

几何、属性版本、形变、矩阵、深度状态、实际相机和目标配置变化均使证明失效。未知着色器、裁剪等恢复原绘制，并使依赖它的后续前序不稳定。无完整深度清除不使用证明；查询只在 AVAILABLE 后读回，失败和上下文退出释放资源。历史存储每 16 个候选帧或超阈值重置，缺少证明只恢复绘制。最终实现等待连续两帧完全相同才查询，避免运动工况每帧重新发起约 7000 次无效查询。

仅 `inspect=occlusion-prefix-audit` 启用，完整模型加载完成后运行。诊断中每对候选和原始帧共用同一完整场景及当前姿态。记录的耗时包含同步读回及缓存效应，不代表持续 FPS。

## 实际浏览器对照

ANGLE Microsoft Basic Render Driver，完整 8868 登记实例，1212×773 画布，机械 240 Hz，观察时积压 0。实例登记数不同于独立 mesh 或 draw 数。

| 最终工况 | 跳过绘制 | 候选 / 原始 draws | 候选 / 原始同步毫秒 | 不同像素 |
| --- | ---: | ---: | ---: | ---: |
| 静态预热 | 5319 | 3986 / 9305 | 972.4 / 1249.0 | 0 |
| 发动机约 548 RPM | 1 | 9304 / 9305 | 1273.9 / 1324.3 | 0 |
| 侧视、右前门 99°、发动机运转 | 0 | 9306 / 9306 | 1249.1 / 1257.8 | 0 |
| 纵剖、开门、发动机运转 | 0 | 9139 / 9139 | 1237.4 / 1232.4 | 0 |

静态预热少画 6,937,268 个三角形，原始整帧 21,582,915 个三角形。普通静止入口已有整帧缓存，因此这一结果不能作为普通静止性能新增收益。发动机仅省 768 个三角形，单对约 4% 时间差不能证明有效动态提速，界面仍约 0.8 FPS。

早期未加稳定门槛时，发动机每帧查询 6947 次，却只复用 1 次，候选 2053.5 ms 对原始 1263.7 ms，明显更慢。负面证据保存在 `engine-before-stability-gate.json`。加门槛后动态查询为 0，消除这项无用查询成本，但没解决遮挡复用依赖范围。

三个通道最早变化的深度对象均为 `C5_flywheel_involute_ring`，原材质 `D12_machined_steel`。它导致后面约 6947 个完整前序证明每帧失效。需要进一步缩小到保守空间依赖范围，不能把全前序方案默认开启或据此宣称 CAD 优化完成。

## 验证与后续

针对性测试通过：微小矩阵变化、目标/前序、投影、属性版本、形变、MSAA、裁剪、未知回调、缺失前序、非有限输入、未完成查询、异常释放、上下文丢失、存储上限和连续运动不重复查询。测试使用实际 Three 对象及受控 WebGL 查询传输，光栅正确性由上述真实浏览器配对另行验证。

最终类型检查、构建通过；11 个机械/导出源文件、16735 字符姿态块与显示质量配置同不可变基线。完整部件及机械目标未收缩。原始证据在 `outputs/occlusion-prefix-reuse/`，日志在 `work/occlusion-prefix-reuse/`。

下一步探索按保守屏幕区域记录深度依赖，必须覆盖浮点变换、形变、近裁面、实际 viewport 和多重采样；未知情况退回完整绘制。尚未实现或验证这个空间方案。
