# 原链接程序深度重放与保守查询

完整 goal ACTIVE，整车 16 项验收 OPEN。本阶段没有省略任何产品绘制，没有证明跨帧缓存有效或稳定帧率提升，普通预览默认不启用此诊断。

## 实际实现

`originalPassDepthReplay.ts` 在 Three r183 原场景 `onAfterRender`、原 render state 尚有效时，按原目标批量重放已记录的不透明绘制。使用原几何、原材质、原参数，逐项核对世界、modelView、normal 矩阵和 morph 权重，以及程序包装对象和捕获时的 WebGLProgram 句柄。自定义回调、非 r183、异常深度模式等均回退原绘制。

自有目标匹配原颜色格式、色彩空间、采样数、24 位深度及实际 viewport；重放只写深度。没有 MSAA 深度 blit，没有修改原资产。异常恢复原钩子和图形状态，自有目标及附带深度纹理只释放一次。

`originalReplayDepthQueries.ts` 用保守 Float32 变换体、额外 2 像素边界和前向深度保护，执行异步 ANY_SAMPLES_PASSED_CONSERVATIVE。每个通道分别验证近处必通过、远处必失败控制，查询 AVAILABLE 前不读结果。

首次查询几何未通过 Three 的常规上传路径，所有体和近处控制均错误地返回零。该样本已拒绝并保留。根因是 renderBufferDirect 依赖已上传的 position buffer；修复用自有退化四边形进行一次无颜色/深度写入、无 clear、无阴影更新的初始化绘制。修复后六个控制全部通过。不能把无 WebGL error 当成有效遮挡证明。
