# 扭杆安装基准：原文澄清与现有原生机构诊断

1977年原始手册第320页明确：安装或更换扭杆时，前后悬架下摆臂两端头
中心的竖直距离应为136–141 mm，同时支承螺栓顶住上摆臂并锁紧。随后的
拆装步骤要求顶起车架到这一尺寸。它解释了图98的136+5标注，不能当成
轮心行程、空载车高或静态预载。

原文另将543M的安装尺寸列为138–143 mm；不可混入543A。满载时上摆臂
应接近水平，是另一状态的定性检查，原段没有角度公差。这些内容已查看
原分辨率扫描，来源和书本SHA在
`../reference/suspension-installation-1977.json`；原始扫描页仅留作本地研究。

## 现有连杆的限定映射

调用实际`lib/suspension.ts`，没有修改任何工作参数。用当前拟合硬点求得：

| 安装竖直差 | 当前拟合轮心位移参数 | 当前拟合下摆臂角度 |
|---|---:|---:|
|136 mm|−131.047 mm|−15.312°|
|138.5 mm|−133.406 mm|−15.601°|
|141 mm|−135.762 mm|−15.890°|

后两列是现有模型的推导结果，不是工厂参数。当前声明零位下摆臂竖直差
约0；当前`droopStop=-0.16m`对应下摆臂竖直差166.890 mm。这揭示安装、
空载、满载三个姿态与限位尚未完成统一标定，不能直接将droopStop改成
136 mm或把安装姿态设为正常行驶零位。

## 实际原生读回结果

直接打开保留的`MAZ543A_Suspension_Master.blend`，在内存中应用上述三个
诊断姿态，读取八站真实rig基准点及实际求值上摆臂/限位螺栓几何：

- 共24个安装基准状态，竖直差最大误差0.0372 µm。这只是rig基准对应，
  不代表铸件孔中心或加工精度已测量通过
- 24个状态中，既有支承螺栓与上摆臂包围盒均严格分离；最小轴向分离
  下界25.443 mm。因此当前未调整螺栓确实没有达到手册所述的接触条件
- 该距离是保守包围下界，不是精确最近表面距离，也未建立螺纹调节范围、
  螺栓支承、接触垫或承载能力。源文件字节未变，没有保存新的blend

实际Cycles对照图只隔离显示一个站的上下摆臂、立柱及原有限位螺栓/锁母。
两个相同机位分别是当前声明零位和138.5 mm安装基准诊断。没有将未调整
扭杆变形、预载、支架或整套装配描绘成已验证状态；它们仍待后续重建/校准。

首轮渲染被旧展示动画复位，两张图几何相同，已拒绝并保留在
`work/cloud-suspension-installation-render-rejected-20261001`，未作为本轮结果发送。
修正只解除不保存的诊断场景中的旧动作，并关闭运动模糊；渲染之后再次
读取真实rig基准：0和138.500035 mm，相机矩阵完全相同。最终两图均已检查。
