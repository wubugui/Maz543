# 显示资产精度、切线追踪与实际导出

2026-09-09。整车 goal 保持 **ACTIVE**，全部 16 项验收 **OPEN**。这是保精度显示优化中的资产检查，不是帧率或整车机械验收。普通入口仍使用主线程显示，完整 Worker 入口仍仅为开发实验。

## 已核实的源头

证据集中在 `outputs/tangent-audit/`。

`audit-decoded-tangents.mjs` 使用网站实际提供的 Draco WASM 解码当前 GLB。抽查车身漆面、窗密封和冷却输入法兰：源文件解码后的切线与上阶段真实浏览器导出的切线逐位相同。12 位 generic 量化把原生零切线变成长度约 0.000423、0.000345 的噪声向量。这个错误不是新的 Blob 封装引入的。

`audit-native-tangents.py` 只读原生 Blender 文件、计算 loop tangents 和关联面的面积，没有保存原生文件。抽查发现零切线及退化 UV；更重要的是，相关原生细面具有非零面积，而当前有损位置量化把其中一些面压塌或扰动成细长面。车身相关原生面积约 5.19e-8 至 5.66e-8 m²、窗密封约 2.34e-8 m²、冷却法兰约 4.28e-10 m²。不能把解码后的退化面误称为原生模型中没有意义的面。

发动机盖的运行时名字 `D12_cover_L_D12_cover_enamel_cover` 没有在所查 `D12A525A_Engine_Master.blend` 中找到；仍需沿真正的生成/合并流程定位，不能据此重导出并覆盖发动机。

## 当前实现与保护范围

`lib/exportTangents.ts` 仅为导出创建轻量 geometry 包装及新的 tangent 属性；位置、索引、UV、法线、形变等与原模型共享，运行时模型不变。

仅当候选切线的每个关联三角形都有**完全相等的位置对**，且同一位置对在所有位置形变目标中也相等，才生成稳定的正交单位方向，保留 tangent.w。没有 epsilon、删面、减面、重新采样或扩大容差。蒙皮、未知属性格式、会张开的形变、关联真实面的顶点均保留并报告未解决。该修正不能恢复已有位置量化丢失的原生细面。

`export-model.ts` 的原 ArrayBuffer 和新 Blob 导出共用这一准备步骤，按源 geometry 缓存包装，最后只释放新建对象。当前准备阶段也遍历隐藏部件，因此浏览器进度中的 632 修复/98 未解决包含未导出的隐藏对象；实际可见整车文件是 616 修复/82 未解决。

## 真实浏览器验证

点击完整 Worker 页面“导出 GLB”，实际下载并保存为 `whole-guarded-tangents.glb`，349,722,392 字节。完整 glTF 校验未截断，**82 错误、0 警告、1,977 信息**。错误仍为非单位切线；校验脚本如实返回失败。涉及真实面的发动机盖和轮胎残留问题没有被自动抹掉。

与上阶段整车导出比较，`guarded-export-comparison.json` 记录：

- 二进制载荷均为 346,418,624 字节；5,982 个变化字节全部属于 tangent.xyz，其他字节变化数为 **0**。
- 位置、索引、UV、法线、图片、形变及 tangent.w 未变。
- 节点 3,226、网格 1,758、图片 9、带形变目标网格 94，数量相同。
- JSON 的 9 个数值差异中，6 个是更新后的切线 accessor 边界，3 个是不同机械时刻的根矩阵。没有冻结求解来伪造相同姿态。

浏览器小纹理样例仍与 stock 封装逐字节相同。真实整车仅导出当前可见姿态，不代表隐藏内构全部包含在该文件中。

## 保留浮点精度的压缩试验

`export-lossless-samples.py` 从原生文件选取车身漆面和一件轮胎，分别导出普通 GLB、五类量化全部设为 0 的 Draco GLB。只写临时样例，不覆盖任何原生/运行时模型。

`verify-lossless-draco.mjs` 用实际网站解码器比较 POSITION、NORMAL、TANGENT、两组 UV 的完整 Float32 位模式。比较保留三角形绕序和重复次数，只允许面存储顺序及循环顶点起点不同，不做舍入、容差匹配或位置焊接。

| 样例 | 三角形 | 全部角点属性逐位相同 | 额外重复顶点记录 |
|---|---:|---|---:|
| 车身漆面 | 10,072 | 是 | 38 |
| 单件轮胎 | 126,804 | 是 | 171 |

唯一顶点属性记录也逐位相同。编码器增加了重复顶点，故不能声称顶点存储或连接索引完全相同。首次按整个顶点多重集合要求相同的检查失败后，保留了这项差异，分开验证完整有向三角形角点记录及唯一属性记录，未放宽浮点精度。

普通样例共 17,807,964 字节，零量化 Draco 为 16,285,152 字节。仅验证这两个对象相对于同次 Blender 普通 glTF 导出；不代表整车全部源值无损，也不代表已有零切线/退化 UV 自动正确。压缩率有限，后续必须评估全车传输和内存，不能重新引入有损量化换取体积。

切线保护测试通过，包括 1e-20 的真实细面不被误修、关联真实面保护、蒙皮、形变张开、稳定重合形变、源属性不变及 tangent.w 保留。Blob 容器与 stock 编码的 12,868/13,176 字节用例（含动画）仍逐字节相同、0 glTF 错误。类型检查及生产构建日志在 `work/tangent-audit/`；生产构建不等于生产浏览器通过。
