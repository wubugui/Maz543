# 静态深度证明的实际法线通道复用

完整 MAZ-543A 产品演示 goal 保持 ACTIVE，全部 16 项整车验收 OPEN。用户要求不减少部件、几何、机械求解或显示精度；本阶段没有修改模型资产、机械公式、位姿更新块、导出或渲染质量参数。新增候选仍默认关闭，整车动态性能问题没有解决。

## 实现与适用范围

`lib/normalOcclusionCache.ts` 通过开发入口 `inspect=normal-occlusion-audit` 接入真实 viewport。它只跳过 GTAO 法线材质的原相机绘制，不处理主颜色、透射或阴影通道。构建静态深度时借用该 GTAOPass 的同一个 MeshNormalMaterial 和原几何，复制原世界矩阵与 morph 权重；借用材质只临时关闭 colorWrite 并恢复，不修改着色器或顶点数据。源几何、材质和部件节点不由缓存释放。

使用独立全尺寸 samples=0、depth24 深度目标；1212×773 的 RGBA8 加 depth24 名义存储约 7.50 MB，另有独立 1×1 控制目标。此值不代表进程私有内存或驱动实际分配量。保持完整静态面片，没有降面数的遮挡代理。

两次完全相同观测仅决定本次静态候选。已保留遮挡物的矩阵、几何属性/版本、morph 权重、组、材质资格、层、包围球、可见性等一旦变化，立即丢弃整个证明和深度快照，并把变化件从后续静态遮挡集合排除。相机或尺寸变化同样使证明失效。后加入对象不破坏既有有效静态子集。

查询体使用上一阶段的关联角点保守屏幕范围与前深度。证书额外扩展 2 像素，前深度提前 2^-17；实际查询再扩展 2 像素、前移 2^-18。只有当前范围被证书完整包含且查询返回零采样才允许省略。运动零件超出范围立即恢复原绘制；新查询异步等待，每帧最多 256 件、最多两批在途，优先三角形最多的对象。每批同时验证近面有样本、远面无样本两个控制，未 AVAILABLE 不读取结果，控制失败不采用证明。

每帧实际法线目标 samples/depth/viewport 仍核验。特殊材质、裁切、线框、自定义渲染回调或上下文丢失回退到原绘制。移除的运动候选不继续由证书 Map 持有。异常、失效与 viewport 关闭释放自有查询和目标并恢复 renderer hook；借用的 normalMaterial 由原 GTAOPass 管理。

## 验证与继续方向

`verify-normal-occlusion-cache.mjs` 使用真实 Three 对象和受控 WebGL 传输，验证证书包含、运动件范围内复用/越界恢复、原颜色绘制保留、移除候选释放、相机/几何/包围球/层/可见性失效、查询可用性、正负控制、异常恢复和资源生命周期。这不是硬件光栅证明。旧静态遮挡/查询生命周期及 90,000 个 Float32 顶点、4,800 个 morph 顶点的范围检查通过。TypeScript 与最终构建通过；11 个机械/导出文件、16,735 字符位姿块和质量设置与既有不可变基线一致。

主线程模式真实诊断操作出现 focus-emulation/CDP 调度超时；转到既有 DEV Worker 后操作正常。没有修改浏览器、驱动、端口或其他应用。Worker 仍未默认启用。

下一步需要定位剩余主颜色、透射、阴影、后处理的实际代价，并验证各通道自己的原始着色器/深度精度。不能把当前法线快照直接用于其他通道。减少重复同步状态查询也值得检查，但不应削掉正确性条件来换性能。最终默认启用仍需要全面实际画面、动态性能、资源与完整产品功能验收。
