## 有据与拟合的边界

拓扑和摩擦盘数量取自已缓存并查看的 1973 图 42 / 44 与正文，详见
[资料记录](TRANSMISSION_REFERENCE_NOTES.md)。源文件打包保存四张原图。

**齿数是由速比推导的一组整数解，不是从原厂零件抄录。** 本次使用
S41=60、S21=48、R40=132、R18=156、长行星轮=36、短行星轮=54。
这组数允许三个等分行星位置共同装配，同时给出 3.2 / 1.8 / 1 / -1.6。
模数 2.5 mm、20° 渐开线、齿侧余量、轴向长度及安装坐标均为重建值，尚未实测。

两排共用行星架，长短行星轮彼此常啮合。以输入角 `a`、行星架角 `c` 为独立坐标，
齿圈 40 为 `c - 60/132*(a-c)`，太阳轮 21 为 `c - 60/48*(a-c)`，
齿圈 18 为 `c + 60/156*(a-c)`，另叠加几何齿相位。行星轮在共用行星架内按
相应齿比自转。三挡各齿轮相对行星架不再自转。

挂挡时浏览器角度积分使用当前车轮侧转速和所选机械挡位；空挡仍保留输入端参考
相位，**没有求解自由涡轮转动**。活塞目前按挡位作几何选择，摩擦盘接触压力、滑差、
弹簧受力及换挡液压尚未完成。轴承滚子仍是未驱动的几何，不能宣称所有部件已仿真。

独立源文件的 0—600 帧是 6 rad/s 输入的 N / 1 / 2 / 3 / R 检查序列。
两份整车原生文件仅安装空挡参考姿态，**没有把这条独立序列冒充整车因果动画**。
整车安装坐标仍沿用旧模型的拟合位置，增速级、变矩器和分动箱之间的轴线闭合待核对。
