## 已落地

`lib/transmission.ts` 逐级展开速比。`lib/mechanics.ts` 删除了倒挡错误回退到 3.2
和固定末端系数 10.5；浏览器新增高低挡、六级带方向转速读数、空挡状态与原书链接。

车轮侧读数由模拟车速反推，泵轮由发动机转速反推。“涡轮折算”是已接合挡位的
约束值，空挡未求解。同步参考车速为 `omega * tireRadius / totalRatio`，不是原车
实测最高车速。加速控制器仍未标定；液力滑差、锁止、换挡摩擦、差速锁和牵引未求解。

暂停及 ×0.035 慢动作统一作用于动力、车速积分、车轮和行驶距离。手动车门、悬架
台架保留独立时间控制。发动机已运行后挂挡不再错误提示“引导流程等待空挡”；
启动前挂挡仍保留提示。

本次未改变 Blender / GLB 几何或原生动画。通用传动齿轮的任意转动仍待替换，
不能把新数据面板视为已完成三维传动联动。
