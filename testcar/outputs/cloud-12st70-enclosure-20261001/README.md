# 12СТ-70/70М 总盖与端子罩外形候选

在前一轮73件电池结构研究上新增压制木质总盖和端子防护罩，共75件。
这是有来源依据、尺寸仍拟合的独立外形研究，没有装进生产整车。
总盖和罩的固定件、准确提手、内部极板以及在车安装均未完成；
16项整车验收仍全部OPEN。

## 来源及明确边界

- [1983蓄电池使用指南](https://www.compancommand.com/literatura/Avtomob/Akkum_Batarei_1983.pdf)
  PDF第11页明确说明12СТ-70/70М族木箱、前壁端子、防护罩和压制木质总盖。
  端子以两个螺钉固定，罩以一个螺栓固定在前壁；这些事实不提供孔坐标或螺纹。
- 同书PDF第8页图4只题为通用“坦克蓄电池构造”，不能指定具体70/70М批次。
  图示罩上的盖固定凸部5、总盖孔2和另一端卡扣13提示盖与罩的保持关系，
  因此不能将两者当成已验证可独立拆卸的机构。图中未给真实操作轨迹。
- [1977 MAZ原说明书](https://drive.google.com/file/d/1quwh1UlmlDyw-WHAIPwLYbylRmNDXUr1/view?usp=drivesdk)
  第206页文字再次支持木箱、前壁端子和防护盒；正文12-СТ-70与图128所见
  12СТ-70М的差异仍保留。该图露出单元盖，不足以确认总盖形状或无盖使用。
- 压制木质不等于已确认胶合板牌号、叠层、厚度或颜色；罩材料也未确认。
  原资料SHA见前阶段README，没有把新扫描图嵌入母版或公开交付。

## 这次实际建出的内容

总盖采用原生立方体与Bevel；罩采用原生立方体、Exact Boolean和Bevel，
形成真实开口U形实体。厚度、间隙、外沿和材质外观均明确标为拟合参数，
不是从泛型图量出的原厂尺寸。没有猜测固定孔、螺栓轴线或盖扣几何。
总盖目前是简化平板，尚未复原图4可见的边沿细节，也不能称为该图的精确复制。
当前盖/罩为位置研究，未与箱体形成已验证支承或固定关系。

当前全部已建几何外廓约583.262×234.000×238.692 mm；原表完整电池名义
尺寸为587×238×239 mm。接近某个数值不等于尺寸、密封、装配或制造验收。

## 新进程读回和保留的失败

- 原73件逐顶点世界坐标与三角形索引完全保留，最大顶点差0
- 新增2件闭合、边/顶点流形、正体积、退化面0、非相邻三角形自交0
- 涉及新件的147对：143对由各向外扩20µm的完整包围盒分离；另外4对
  完整包围盒重叠，实际Blender Exact Boolean交集为空，同时表面交叉0
- 原生Boolean的全包含、分离、相交立方体控制分别得到预期非零、空和
  非零交集，避免将“表面不交叉”误认作“没有包含碰撞”
- 罩的三个分片包围盒仅检查三角表面覆盖，不单独用于证明实体内域；
  当前所有罩三角形均在覆盖范围内。原生Boolean也不是形式化数值证明
- 首版总盖高度只考虑旧73件，和新罩出现93对相交三角形。现已把新罩
  纳入盖高度的拟合；首版母版、图片、失败JSON和日志保留在
  `iteration-01-lid-hood-intersection`，未删掉失败来制造通过
- 首版展开图上缘截断，现扩大同一正交机位画幅，两张最终图均保留完整外形

`native-readback.json`记录具体范围与数值。这里是当前静态几何检查，
不代表电气绝缘、接触/紧固强度、连续拆装净空、密封或整车验收。
