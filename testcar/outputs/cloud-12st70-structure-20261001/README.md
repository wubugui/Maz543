# 12-СТ-70 / 70М 木箱电池结构研究

这是独立、未装车的原生结构候选，不是已完成的电池或1977整车装配。
已按原资料建立木箱、两条钢带、三个真实四腔槽、12个单元盖/加液口、
串联连接与前壁耳式端子。极板包、隔板数量、电解液、端子防护罩、总盖
和在车摆位仍未建；16项整车验收仍全部OPEN。

## 直接核对的依据

- [1977年MAZ技术说明原书](https://drive.google.com/file/d/1quwh1UlmlDyw-WHAIPwLYbylRmNDXUr1/view?usp=drivesdk)，第206页正文及图128。正文称12-СТ-70，图中标签实际为12СТ-70М；这个版本差异保留，不能把图像当成已确认具体生产批次
- [1983年《铅酸起动蓄电池使用指南》](https://www.compancommand.com/literatura/Avtomob/Akkum_Batarei_1983.pdf)，PDF第5页尺寸表、第11页构造正文；均已实际查看页面
- 两资料支持12单元串联、前壁端子及防护罩；1983指南进一步明确每四单元共用一个四腔硬橡胶槽，三个槽放入木箱，槽间穿两条钢带，木箱用БТ-783耐酸漆。不能改画成12个独立槽或现代单体塑料外壳
- 1983表对70与70М均列587×238×239 mm、24 V/70 Ah。四组在车并联280 Ah是1977说明的名义连接；本文件没有模拟电化学或验证实际容量

## 建模与未知项

73个实际几何件通过Blender原生方体/圆柱、Curve、Boolean、Bevel与Weld构成。
每个四腔槽是真实减去四个腔体的实体，不是表面画格线。13个导体曲线源
保留在SOURCE_CURVE对象中，可重新转换；当前导体是原生转换后的可编辑网格。

壁厚、槽间距、木板拼缝、盖/加液塞/引线形状、孔径、材质色调均为拟合。
前壁端子罩、木质压制总盖、准确提手和内部铜嵌件尚缺构造尺寸，没有用
无依据的几何补齐。当前外廓约576.762×233×229.500 mm；它小于完整产品
名义尺寸，文件中另有不参与渲染的587×238×239 mm参考框。不能据参考框
或部分几何尺寸宣布电池尺寸验收通过。

槽内极板、隔板及电解液没有虚构；因此切开/隐藏盖后看到的是本次已经
建出的腔体，不是宣称真实电池内部为空。重量、质心、化学容量、散热、
绝缘距离、密封和负载能力均未验证。

## 实际保存与读回

- 新进程打开保存的母版，73件均闭合、边/顶点流形、正有向体积，自交检查0
- 三个槽共12个腔：逐腔向下实际射线到达槽底，四向射线遇到侧壁/隔板，
  排除只按命名/数量声称有12腔
- 13个曲线导体的原始封口/轮廓存在重复顶点，首轮非流形边为136或40；
  原生转换+0.1µm Weld后修复，原曲线/网格世界顶点集合双向最大差0
- 26处预期导体连接具有表面交叉，按拟合焊接接口记录；这不是焊缝或接触
  电阻证明。其余794对导体/钢带以外扩包围盒分离，未发现非预期接触。
  这些是当前静态几何范围结果，不是电气安全或绝缘验收
- 未修改或保存任何生产整车、网页资产或原电池尺寸参考母版

`native-readback.json`保留全部局部结果及限制。脚本退出0仅说明其中的
明确断言执行完成，不等于完整电池或整车验收。
