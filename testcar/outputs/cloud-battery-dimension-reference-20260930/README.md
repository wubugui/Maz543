# 12ST-70 dimensional reference only

This file is a reference cuboid, not reconstructed battery geometry and not a vehicle installation. The object is wire-display and render-hidden deliberately.

The 1983 official starter-battery guide table 1, PDF page 5, lists 587×238×239 mm, 24 V, 70 Ah at the 10-hour rate. Source: https://www.compancommand.com/literatura/Avtomob/Akkum_Batarei_1983.pdf

Local X/Y/Z mean length/width/height only. No relationship to vehicle axes or original 1977 mounting coordinates has been established. Do not infer casing wall thickness, terminal position, bracket holes, box size or service clearances from this cuboid. All whole-vehicle acceptance gates remain OPEN.

Recreate with official Blender 4.5.13 and scripts/build-battery-dimension-reference.py. The script saves and reopens the independent file and checks its dimensions; it never opens or changes a vehicle master.
