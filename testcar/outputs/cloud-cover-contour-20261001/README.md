两份独立整车候选已经保存并新进程读回。当前第2轮为45mm拟合宽平台/低区，
实际局部与整车Cycles图均已完成并核对来源SHA。第1轮图像完整保留在历史目录。
原生产母版及网页GLB没有替换，16项整车验收全部OPEN。

## 可见依据与拟合范围

主要依据是[Adrian Kot的MAZ543A原图](https://www.flickr.com/photos/junktimers/8680069876/in/album-72157633346929988/)，
并核对[裸底盘照片](https://fototruck.ru/photo/1875/)、
[博物馆照片](https://fototruck.ru/photo/232059/)及
[带后期改装的车辆](https://fototruck.ru/photo/83391/)的相同区域。
来源、作者、日期标签、像素SHA和车型限制见`reference/hood-photo-register-20261001.json`。
照片像素仅留本地研究，未加入新公开母版。

可读外形是中央宽隆脊、左右提手较低区及外侧肩部，沿车身纵向延伸、圆滑过渡。
这些是连续面起伏，不是粘在平板上的几根窄圆管。原光板没有这些轮廓。
照片不能给出精确压型截面、深度、板厚、背面加强或具体生产批次。

本轮用原生Geometry Nodes的局部Position、数学节点、Smootherstep和Set Position
形成连续宽平台/低区，置于原Solidify之前，保留原生薄壁、开孔和分板Boolean。
幅度45mm、横向周期490mm、前缘90mm/后缝240mm渐消区均为显式拟合参数。
不是制造厂压型数据，也没有用照片像素推导伪精密公差。

两只提手从前一阶段保留，脚点按新求值曲面射线重新落脚，仍是3mm拟合埋入。
实际连接件/焊接方式/承载能力均未验证。修改节点幅度后需重新匹配脚点，
不能把这个研究参数当成已约束好的产品机构控制。

28mm正弦浅起伏的两份母版、构建脚本、报告和实际局部/整车图保留在
`iteration-01-shallow-cosine`。其原生读回通过，但实际图片里的宽隆脊/低区
仍过于圆滑、视觉表达偏弱，因此没有凭数值检查将它当成外形完成。

第2轮用较宽的平顶/谷底及圆滑过渡继续接近照片。其尺度依然拟合，
不能仅因视觉有所变化便宣称原厂形状或整车准确性验收通过。
第2轮局部图能辨认中央宽隆脊与两侧低区；仍需核对离散网格的转折采样、
外侧肩部、前沿和背面构造，尚不是准确的制造截面。
