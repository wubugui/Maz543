# 实拍依据：前盖两只提手独立候选

已主动从网上取得并实际查看4张有摄影者/页面来源的MAZ543A照片，
按可见结构在r3的两份整车候选上补建前盖顶面两只横向拱形提手。
这是一个可核对的外形遗漏修正，不是整车验收或生产替换。

## 实际改动

只新增`BL_Photo_front_cover_top_grip_-1`与`BL_Photo_front_cover_top_grip_1`。
通过原生Bezier、圆形Bevel和Weld保持可编辑曲线，两端脚点从当前盖板的
实际求值表面向下射线定位；拟合宽180mm、拱高45mm、管径16mm。
这些数值是视觉拟合，没有冒充照片测量或原厂尺寸。

提手脚端拟合埋入盖面3mm，连接件/焊接方式、真实脚座和承载均未确认。
作为附着假设，两只提手随现有前盖运动。原先两条3点竖向锁扣代理、
它们的诊断转轴与−100°动作全部保留，不能把照片里的提手改名当成锁扣。

照片还显示当前盖面缺少中央宽隆脊、两处提手低区和外侧肩部；现有矩形
高台阶也未得到照片支持。本阶段没有把“补提手”说成盖板已准确复原。

## 新进程检查

- Master原8712个、Textured原6932个几何对象的求值局部顶点/三角形指纹、
  世界矩阵、父级及对象渲染隐藏状态与各自r3源一致；不是全部对象属性证明
- 两只新提手均闭合、边/顶点流形、正体积、退化面0、非相邻三角形自交0
- 每份母版四个诊断姿态中，提手对盖板的附着假设顶点差0
- 每个姿态每只提手和盖面有56对交叉三角形，属于未验收脚端埋入；
  所查表面交叉没有涉及其他部件。这不是完整包含、连续扫掠或承载证明
- 两份r3源和保存后的候选在读取/渲染时未覆盖；生产母版/网页GLB未改

原r3锁扣早期释放干涉和前唇/格栅交叉仍未修复，16项整车验收全部OPEN。
