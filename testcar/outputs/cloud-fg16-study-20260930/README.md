# ФГ16 / FG16 独立原生结构研究候选

这是按1977年第三版图137研究的独立小型候选，未晋级生产。明确失败项：光学碗与7号底座仍有617对三角形的刚性表面交叉，实际座孔/接口构造未核实，装配连接为OPEN。生产两份整车母版、浏览器GLB和原灯位置不变；全部16项整车验收仍为OPEN。

## 原始依据与拟合边界

- 原书：[《Колесное шасси МАЗ-543 и его модификации》技术说明，第三版，莫斯科，1977，Военное издательство Министерства обороны СССР](https://drive.google.com/file/d/1quwh1UlmlDyw-WHAIPwLYbylRmNDXUr1/view?usp=drivesdk)
- 印刷第27页原表在МАЗ-543А列列出ФГ16，无后缀。印刷216–217页正文和图137实际原图已逐一查看；两页原始文件SHA保留在shareable母版的SOURCE_REFERENCE_METADATA.json
- 正文明确玻璃平滑、透明、无色；图137支持前玻璃、独立边框/密封圈、内凹光学元件、中央灯泡/底座、弧形空腔后壳及导线路径的关系。清玻璃与空心反射碗是结构依据，不只是材质替换
- 图137没有制造尺寸。所有直径、深度、曲率、壁厚、灯泡和底座尺寸、线径、材质反射率/粗糙度/IOR均为FITTED。约240 mm外径和180 mm轴向量级来自旧照片拟合，不是原厂参数；不将模型计算小数解释为制造精度
- 图137是未标尺寸的示意剖面，轮廓并未完成摄影标定或像素重合验收；玻璃拱度、光学曲线及底座细节仍是拟合
- 原文水平总行程340°。模型以±170°作便利操作范围，零位及止挡方向为拟合；垂直方向只说“到止挡”，本候选没有发明垂直角范围
- 未按2920±25 mm整车灯顶名义值缩短生产支杆，也没有将独立展示座高度当成车上安装高度
- 原始扫描页只供本地研究，公开再分发许可未核实。本任务没有发布扫描页；SHAREABLE版本完全不含原手册图像像素，只保留来源/版次/页码文件名/哈希
- 补充避免混型：[OSVAR现代目录，第25页索引／印刷50–51页](https://www.td-oat.ru/site/images/05-svet.pdf)区分无后缀与E/I/K/N配置。现代目录不是1977年543A装车同版本证明，本候选没有据其改成12V或移用后缀零件

## 原生结构与文件

- 9个源部件几何对象：玻璃、边框、密封圈、灯泡玻璃、灯泡金属基部、光学元件、后壳、7号底座、布线路径。它们对应图137的1–8号类别，不是原厂BOM数量
- 9号固定螺钉仅有不可渲染的来源定位标记，几何/轴向/配套安装支架未建，不能把定位点称为螺钉模型
- 原生Bezier/POLY曲线源保留；通过Blender原生转换、Screw、Solidify、Boolean、Weld、Bevel建模，无脚本手工拼网格顶点/面
- 布线只有一个可编辑路径包络，不代表导体数量或已建立电路。灯丝、电接点、真实灯座锁定细节未建
- 深色立柱/底盘是明确标注的展示夹具，不是MAZ安装件。原支架、垂直铰链/止挡、驾驶室控制机构、安装硬点和旧位置AO均未验收
- FG16_Native_Structural_Study.blend：本地研究版，含两页已打包原图
- FG16_Native_Structural_Study_SHAREABLE.blend：无扫描像素版本，含相同可编辑几何/控制/两个场景及来源元数据；可保存在独立开发分支，远端交付状态须另行核实
- cycles-assembled.png、cycles-section.png：官方Blender 4.5.13，CPU 4线程，Cycles 64采样实际渲染。半剖仅切玻璃/边框/密封/光学元件/外壳，灯泡、底座和线缆保留全体，属于展示剖切

## 失败记录保留

- iteration-01-retained-failed：Euler限位绕回、电缆封口未焊合、未分类交叉、剖切选择误含源曲线
- iteration-02-retained-not-accepted：修正夹限/线缆后，灯泡金属基部仍有轴向非流形边和反向体积
- iteration-03-retained-not-accepted：基部闭合但法线仍反向；无使用者的参考图在保存读回时丢失，后改为显式保留
- iteration-04-retained-diagnostics：原生孔口约1.27纳米重复点触发自交；展示夹具与壳体有175对三角形交叉；保留最初单射线包含诊断
- 最终通过原生Weld修孔口、仅将非原车展示 collar下移4 mm；原有候选不覆盖。共享工具路径消失导致的未启动第五轮exit127另存build-interrupted-missing-tool.log，随后使用恢复的MAZ专属官方4.5.13执行

## 下一步与停止条件

优先取得ФГ16同年代装配图或原件测量，核实光学碗/底座接口、边框扣合/螺钉、密封圈压缩、原安装支架和垂直机构。解决刚性干涉并建立真实连接后，再独立讨论是否装回整车。当前文件只是结构研究候选，不能用作生产替换或灯光性能证明。
