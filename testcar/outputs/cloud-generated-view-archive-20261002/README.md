# Original MAZ engineering views

These are the remaining eleven original PNG render files from prior cloud work, published byte-for-byte through the GitHub plugin. They are historical studies and diagnostics, including failed installation proposals. They are not new renders, factory references, the current combined vehicle or evidence of whole-vehicle acceptance. All16 vehicle gates remain OPEN. Source filenames, complete byte hashes, pixel dimensions and decodedRGBA hashes are in manifest.json. Each image is stored once as its original PNG. Manual-book scans are excluded.
