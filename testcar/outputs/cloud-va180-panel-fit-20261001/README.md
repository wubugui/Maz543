# Partial VA180 front study in the independent cab candidate

This editable Master is a fitted review candidate. It combines the retained
steering/cab-panel candidate with the partial photographic VA180 front study.
Production files remain unchanged; all 16 whole-vehicle gates remain OPEN.

The existing B4 position resembles the observed device, but drawing leader 64
conflicts with the original caption's fan-switch assignment. This installation
does not resolve that conflict or establish a factory mounting position. The
device still omits unreadable voltage/minor markings, hidden electrical parts,
rear fittings and unknown original dimensions.

The existing native B4 Boolean hole sets the fitted envelope. The device uses one
uniform scale of approximately 0.679226, with a nominated 0.3 mm radial gap in
panel-local coordinates. This is an explicit fitting choice, not an original
tolerance. Its visible face now has a separate real window, partial observed
characters, correction screw and independently operated button.

All 10,405 pre-existing objects remain. Exactly eight named B4 proxy objects are
hidden and retained; no other old geometry is removed or hidden. Saved-file
readback checks authored geometry/UV, original parent relationships, world/local
matrices, material-slot names, collection memberships and object hide flags.
Four retained seat-base regions each still have 900 vertices and 300 faces and
their mesh remains eligible through an enabled primary render-layer path.
Eligibility alone does not prove unobstructed pixels.

Ten incoming physical study solids produce 20 broad-phase comparisons with the
existing panel and cabin mesh and no surface-triangle intersections. This does
not prove full solid containment, continuous travel clearance or whole-cab fit.
The three previously documented column/cushion and panel/wall intersections
remain unresolved.

An additional 192-ray check through the actual plate at the fitted casing radius
finds zero obstructions. Disabling the retained panel opening Boolean produces
192 hits; restoring it returns zero. This is a static sampled opening check.
The first probe assumed an individual Boolean rather than the retained collection
operand and stopped before measurement; its failure record is retained.

Button inputs 0, 0.5, 1 and 0 are sampled in the actual saved candidate. Only the
button controller, stem and cap move, by the fitted scale-adjusted displacement;
all other world matrices remain unchanged. These inputs are review travel, not
a verified manufacturer stroke or electrical simulation.

The original study's editable curves, Boolean tools and packed-font license are
retained. Reference-photo pixels are not imported. Construction uses native
library append and parenting; it does not reconstruct the vehicle or create
manual scripted meshes.

A separate saved-file comparison against the standalone device verifies all 28
appended object identities and fitted world transforms, authored geometry/UV,
parent semantics, material-slot names, hide-render flags and packed font data.
It reports zero failures. It does not inspect every modifier property or material
node. Both same-camera close-up images are actual whole-Master Cycles renders;
no additional geometry is hidden to make either picture. Their low-sample noise
and limited installed scale-legibility remain visible and are not retouched.

Source identities and detailed evidence are in `build.json`, `readback.json` and
`aperture-probe.json`. Actual images and their per-image provenance are added only
after rendering. Compilation, local contact checks and successful publication
must not be described as vehicle acceptance.
