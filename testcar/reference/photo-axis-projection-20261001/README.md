## 已完成的有限计算

像素点位、图片尺寸、EXIF 摘要及来源在 `landmarks.json`。坐标均针对下载文件原尺寸，左上为原点，u 向右、v 向下。四轴从前至后的站位为 0、2.2、5.5、7.7 m。手工中心按可见轮毂端部的中心特征拾取，暂给约 ±3 px 的标注容差；这不是统计置信区间，尚未覆盖实体和成像系统误差。

对四点拟合一条三维直线的透视像：u=(a·s+b)/(e·s+1)，v=(c·s+d)/(e·s+1)。此前实际计算记录保存在 `recorded-results.json`：

- 1875：二维点距离 RMS 约 **1.5 px**；交比约 1.1917
- 83391：二维点距离 RMS 约 **1.1 px**；交比约 1.1844
- 手册轴站对应交比 1.190476；图片交比沿四点最佳拟合直线测量

这些残差说明照片与名义轴站的一维投影**未出现超出当前粗点位精度的明显冲突**。它们不证明完整车体尺寸、相机或镜头已准确，不是对现有模型的测试，也不是独立验收。只有四点、五个项目参数，数据冗余很少；需要保留此局限，不能用小残差反证驾驶室正确。

## 能辨识与不能辨识

四个近共线轮心主要约束纵向一维透视关系及纵向消失点；纵向消失点不是完整地平线。现有数据不能独立唯一确定焦距、距离和完整相机姿态。即使把焦距作为已知值，围绕该三维直线的相机旋转仍缺独立约束。未知裁切/主点和镜头畸变进一步增加歧义。

记录中的非唯一性例子：1875 在假定 1000 与 3000 px 焦距时，相机至第一轮毂的条件距离分别约 9.7 与 21.1 m；两者都产生同一条拟合投影。这是**不能唯一解相机的反例**，不是实际拍摄距离的估计区间，更不是推荐相机参数。

2.375 m 轮距未参与计算：这些照片缺少可确认的对应左右轮中心点，而且看见的轮毂端面中心不在轮距所指的轮胎中面。前两轴转向会使外轮毂中心相对名义轴站偏移，悬架/地面也会令各轮中心不严格共线。不能把这类系统误差压成模型的毫米级尺寸调整。

可以可靠标注作**后续对照、但尚无已知三维坐标**的图像特征包括：挡风玻璃开口拐角、格栅边界、灯具中心、前罩外轮廓，以及顶把手和前缘件各自的位置。玻璃圆角/橡胶边、弯曲外轮廓及被遮挡的接缝有点位歧义；当前模型坐标不能给它们自动赋予真实尺寸。应先用独立基准确定相机，再把这些特征作为未参与相机拟合的检查点。

可探索车架已确认的纵向直梁、横梁和确有垂直定义的长边方向以补足消失点；这几张照片中的短边、遮挡和驾驶室自身斜面尚不足以构成可靠的正交消失点标定。不可把斜窗框、屋顶斜面或保险杠造型边直接当正交坐标轴。
