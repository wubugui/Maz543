## 保存原轮次与两项边界修订

`attempt-01/`保留首轮11文件202280B的原字节，包括代码、报告、真实日志、
终态、验证和清单。它们经移动归档而非再存整包副本；
`attempt-01-preservation.json`记录原路径到归档路径及SHA的映射。
首轮报告和清单仍记其真实执行时路径，不改写历史证据。

首轮在有限保存输入上exit0、原五组测试通过。随后静态审查发现两个边界：

1. 镜面NORMAL细分组合法为空，却标成UNRESOLVED_CORRESPONDENCE。修订后明确
   `NO_TRIANGLES_IN_GROUP`，分母0、最大值null；真正未决组列表未清除或更换。
2. 独立运输辅助处理非有限组件时，方向null正确，但完整记录的最大绝对差可能
   是NaN。修订后完整记录可用`allow_nan=False`序列化，明确有限可比组件分母、
   非有限组件对/两侧数量、有限相等和差异次数；非有限组件不会被略去当成相等。
   全域最大向量差/绝对差/ULP在含非有限值时为null，有限组件最大绝对差另列。
   状态明确`NONFINITE_COMPONENTS_NOT_NUMERICALLY_COMPARABLE`；字节差仍看全部组件。

只在原第2/4/5测试组加入这两个边界，没有增加验收框架、改动旧UV辅助/比较器，
或放宽epsilon。当前源代码在本目录；修订后的运行证据只在`attempt-02/`。

## 执行证据与复验前提

复用固定replay_capture的读取/转换/旧记录和analyze_uv的有向POSITION分组/
组件比较；实际桶计数、未决项、法线/UV及签名均对回旧analysis。
原保存数组读取器拒绝非有限raw/位置/UV数值；修订的运输辅助独立非有限负控

旧nonzero最大值仍按转换后的原`~zero`掩码计算。
